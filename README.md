# PhotoSort

PhotoSort is a mobile app built with React Native + Expo to help users sort, organize, and review their photos.

## Features

- Import photos from the device gallery
- Categorize photos by life event or album
- Filter by category
- View statistics and recent items
- Local persistence for the current organization state

## Tech stack

- React Native
- Expo
- TypeScript
- AsyncStorage
- Expo Image Picker

## Getting started

1. Install dependencies:
   npm install

2. Start the app:
   npm start

3. Run on iOS or Android:
   - iOS: npm run ios
   - Android: npm run android

## Notes

This is a functional MVP to demonstrate the photo organization flow. It is designed to be easy to extend with AI-based grouping, cloud sync, or multi-album management.
